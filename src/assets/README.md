# assets

Esta carpeta está vacía a propósito: el juego no usa archivos de imagen ni de sonido.

- **Gráficos:** todas las texturas se dibujan por código en `src/scenes/BootScene.js`, sobre un canvas, con degradados, halos y reflejos.
- **Audio:** los efectos y la música se sintetizan con la Web Audio API en `src/systems/Audio.js` y `src/systems/Music.js`.

Si en el futuro se agregan imágenes o sonidos, van en esta carpeta.
